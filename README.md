## ✨ Sobre o projeto

Aplicação web demonstrativa de um **painel de gestão imobiliária**, com navegação por módulos, indicadores de operação, carteira de imóveis, acompanhamento visual de contratos e visão financeira. Desenvolvida para apresentar habilidades de **desenvolvimento frontend, interfaces empresariais e experiência do usuário**.

> 🌐 **[Acessar demonstração online](https://sistema-gestao-imobiliaria.vercel.app)**

## 🧩 Funcionalidades

| Módulo | Funcionalidades demonstrativas |
|:--|:--|
| 📊 **Dashboard** | Indicadores, gráfico de ocupação e vencimentos |
| 🏘️ **Imóveis** | Carteira com pesquisa e filtros por situação |
| ➕ **Cadastro** | Inclusão de imóveis com armazenamento local no navegador |
| 👥 **Clientes** | Listagens fictícias de proprietários e inquilinos |
| 📝 **Contratos** | Visualização de vigência, valores e situação |
| 💳 **Financeiro** | Listagens de cobranças e pendências fictícias |
| 🗃️ **Documentos** | Conceito de arquivo digital para gestão documental |

## 🚀 Executar localmente

É necessário ter Node.js e npm instalados.

```bash
git clone https://github.com/LuizMarquezin12/sistema-gestao-imobiliaria.git
cd sistema-gestao-imobiliaria
npm install
npm run dev
```

Para gerar o build:

```bash
npm run build
```

Os arquivos gerados ficam em `dist/`.

## 🔐 Segurança e escopo

**Este é um projeto demonstrativo de frontend, não um sistema de produção.** Não possui autenticação, backend, banco de dados remoto, upload real de documentos, integração bancária ou emissão de boletos. Os dados exibidos são fictícios e os cadastros de teste são armazenados apenas no navegador (`localStorage`). **Não insira dados pessoais reais.**

## 🌍 English summary

**Real Estate Management Dashboard — Frontend Portfolio Demo.** Responsive property-management interface showcasing portfolio filters, dashboard metrics, client lists, lease tracking, financial summaries and a digital archive concept. All data is fictional. Demo entries are stored locally in the browser; no production backend is connected.
